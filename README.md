# 深圳长者公园指南

> 语言 / Language：[English](README_en.md)

一款面向深圳老年朋友的微信小程序，提供公园导览、适老化评分与出行辅助，帮助长者快速找到适合休闲、锻炼和社交的绿色空间。

## 体验小程序

使用微信扫描下方二维码，即可进入「深圳长者公园指南」小程序。

![深圳长者公园指南小程序二维码](attachment/qr-code.jpg)

## 项目简介

「深圳长者公园指南」汇集了深圳 **22 个主要公园**的基础信息，围绕长者的实际需求（无障碍通道、休息座椅、遮阳设施、健身器材、安静散步等）提供统一的导览入口。

小程序以适老化设计为核心：大字号、高对比配色、简洁的交互流程，让老年用户无需学习即可轻松使用。当前已覆盖福田、南山、罗湖、宝安、盐田、龙岗、龙华、坪山等多个行政区。

## 核心功能

### 公园列表与搜索
- 以卡片网格展示所有公园的封面、名称、评分与所在区域。
- 支持按公园名称或区域关键词实时搜索，输入即出结果。

### 标签筛选
- 提供多种筛选标签。
- 一键切换，快速定位符合特定需求的公园。

### 公园详情
- 多角度实景照片轮播，直观了解公园环境与设施。
- 展示 5.0 分制综合评分，并以评级徽章标注公园等级。
- 以简洁标签概括核心特点（如「座椅多 | 无障碍友好 | 适合散步」）。

### 图片预览
- 点击照片进入全屏预览，查看高清大图。
- 支持两种切换方式：左右滑动、左右按键（`‹` / `›`）。
- 底部实时显示当前序号 / 总数，长图支持上下滚动查看。

### 适老性五维雷达图
- 从 5 个维度可视化呈现公园的适老化程度，一目了然。
- 点击下方维度可在雷达图上高亮对应评分，并显示具体分值。

## 评分体系

综合评分基于各公园适老性五维评分的**加权总分**，换算为 **5.0 分制**（保留 1 位小数）。同时根据评分百分比划分为四个等级，每个等级使用不同颜色区分：

| 评分百分比 | 等级 | 颜色 |
| --- | --- | --- |
| ≥ 85% | 优 | 浅绿 `#67c23a` |
| 70% – 84% | 良 | 深绿 `#2e8b57` |
| 55% – 69% | 一般 | 橙色 `#ff7d00` |
| < 55% | 待改善 | 黄色 `#e6a23c` |

## 适老性五维评分维度

雷达图从以下 5 个维度评估公园的适老化程度（每项 0–100 分）：

| 维度 | 说明 |
| --- | --- |
| 场地无障碍 | 无障碍通道、坡道等通行便利程度 |
| 安全与风险 | 园内安全设施与潜在风险状况 |
| 运动配套设施 | 健身器材、步道等运动设施完备度 |
| 环境舒适度 | 遮阳、绿化、休息座椅等舒适程度 |
| 交通便利性 | 地铁、公交等公共交通可达性 |

## 项目背景

随着深圳老龄化程度加深，老年群体对户外活动场所的需求日益增长。然而公园信息往往分散于多个渠道，且较少围绕长者的实际需求进行梳理。老年人在选择活动场所时，常因缺少适老化信息而感到不便。

本项目通过汇集深圳主要公园的适老化信息，帮助长者便捷、清晰地找到适合自己的公园。

## 图片与分包

小程序代码包单个包大小限制为 2 MB。本项目的详情图（26 个公园共 286 张）全部打进代码包，由脚本按体积自动切分到 8 个分包（`pages/d1` ~ `pages/d8`，每个约 1.4–1.7 MB），主包只放 26 张封面（约 740 KB）。

为保证仓库里每张照片只存一份：

| 位置 | 内容 | 是否入库 |
| --- | --- | --- |
| `src/pages/dN/img/<公园id>/` | 750px、≤55KB 的详情图，唯一参与打包的图片 | 是 |
| `src/assets/parks/<公园id>/cover.jpg` | 列表页封面，主包使用 | 是 |
| `../elderly-park-guidance-assets/originals/parks/` | 高清原图（项目外的素材库，可用 `PARK_ORIGINALS` 指定） | 否（不在仓库内） |
| `dist/` | 构建产物，可随时重新生成 | 否（已忽略） |

修改或新增公园照片时，把原图放进素材库后执行：

```powershell
node scripts/build-local-photos.js   # 重新压缩、重新分包，并更新 app.config.ts 的分包配置
npm run build:weapp
```
