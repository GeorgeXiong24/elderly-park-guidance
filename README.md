# 深圳长者公园指南

> 语言 / Language：[English](README_en.md)

面向深圳长者的微信小程序，汇集公园信息与适老化参考数据，帮助用户查找公园、了解设施并规划出行。

## 体验小程序

使用微信扫描下方二维码，打开「深圳长者公园指南」小程序。

![深圳长者公园指南小程序二维码](attachment/qr-code.jpg)

## 项目简介

项目目前收录深圳 **27 个公园**，覆盖福田、南山、罗湖、宝安、盐田、龙岗、龙华和坪山区。用户可以按名称或行政区查找公园，也可以查看公园位置、设施标签、评分及相关出行信息。

## 功能

- **公园列表与搜索：** 以卡片展示公园封面、名称、评分和所在区域；支持按公园名称或区域关键词搜索。
- **标签筛选：** 可按无障碍设施、平缓步道、座椅、遮阴、健身设施等标签筛选；同时选择多个标签时，结果需同时符合所有已选标签。
- **附近地图：** 查看当前位置和公园地图标记。选择公园可打开详情或调用地图导航。使用此功能需要允许小程序访问位置信息。
- **公园详情：** 查看照片、设施标签、五维雷达图和五分制综合评分。详情页还提供公园及附近医疗点的位置、导航入口；医疗点支持拨打电话。
- **图片预览：** 全屏查看公园照片，支持左右滑动和屏幕上的前后切换按钮；显示当前图片序号，长图可上下滚动。

## 评分说明

项目数据包含各公园的五维评分（每项 0–100 分）、加权综合分和五分制综合评分。当前这些分数以内置数据提供，不是在小程序运行时根据用户输入或实时测量计算。

详情页按五分制评分对应的百分比显示等级：

| 评分百分比 | 等级 | 颜色 |
| --- | --- | --- |
| ≥ 85% | 优 | 浅绿 `#67c23a` |
| ≥ 70% 且 < 85% | 良 | 深绿 `#2e8b57` |
| ≥ 55% 且 < 70% | 一般 | 橙色 `#ff7d00` |
| < 55% | 待改善 | 黄色 `#e6a23c` |

雷达图展示以下五个维度：

| 维度 | 说明 |
| --- | --- |
| 场地无障碍 | 无障碍通道、坡道等通行便利程度 |
| 安全与风险 | 园内安全设施与潜在风险状况 |
| 运动配套设施 | 健身器材、步道等运动设施 |
| 环境舒适度 | 遮阳、绿化、休息座椅等环境条件 |
| 交通便利性 | 地铁、公交等公共交通可达性 |

> 公园设施、评分、地址及医疗点信息为项目内置参考数据，可能随时间变化；出行前请核实最新信息。评分仅供参考，不代表官方评定。
