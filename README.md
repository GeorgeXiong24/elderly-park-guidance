# 深圳长者公园指南

> 一款面向深圳老年朋友的微信小程序，目前处于开发阶段。

## 核心目的

「深圳长者公园指南」是一款面向深圳老年朋友的微信小程序，旨在提供便捷、贴心的公园导览服务，帮助长者快速找到适合休闲、锻炼和社交的绿色空间。

## 项目背景

随着深圳老龄化程度的加深，老年群体对户外活动场所的需求日益增长。然而，公园信息往往分散于多个渠道，且较少围绕长者的实际需求（如无障碍通道、休息座椅、遮阳设施等）进行梳理。老年人在选择活动场所时，常因缺少适老化信息而感到不便。

## 开发目标

- 汇集深圳主要公园的基础信息，提供统一、易读的公园导览入口；
- 围绕长者需求提供特色筛选维度，如无障碍通道、休息座椅多、遮阳凉亭、老年健身器材、安静散步等；
- 以适老化设计（大字号、高对比、简洁交互）降低使用门槛；
- 通过搜索与多标签筛选，帮助长者快速定位适合自己的公园。

## 公园功能模块规划

为每个公园规划标准化、适老化的信息模块，确保长者能够快速、清晰地获取所需信息。各模块规划如下：

### 1. 公园示例图
为每个公园提供多角度实景示例图，让长者无需亲临现场即可直观了解公园环境与设施，辅助判断该公园是否适合自己的需求。

### 2. 综合评分
对每个公园给出 5.0 分制的综合评分，直观反映公园的整体品质与受欢迎程度，方便长者对不同公园进行横向比较。

### 3. 精准地理定位
提供公园的精确坐标与地图位置，帮助长者准确掌握公园方位，并结合地图清晰展示周边道路与主要出入口。

### 4. 核心特点总结
以简洁明了的标签（如「座椅多 | 无障碍友好 | 适合散步」）概括公园的核心特点，让长者一眼抓住关键信息。

### 5. 适老化评分雷达图
从无障碍、休息设施、遮阳、健身、安静等多个维度对公园进行适老化评分，并以雷达图形式可视化呈现，帮助长者全面了解公园的适老化程度。

### 6. 科学运动时长建议
根据长者身体状况，提供科学的运动时长与强度建议，引导长者在锻炼与休息之间保持合理平衡，倡导安全、适量的运动方式。

### 7. 公共交通指引
提供地铁、公交等公共交通线路指引，并接入前往导航软件的 API，支持一键跳转导航，帮助长者便捷规划出行路线。

### 8. 人流高峰时段提示
标注公园的人流高峰与低谷时段，帮助长者避开拥挤，选择相对安静、安全的时段前往，提升游园体验。
